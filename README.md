# Practice & Replication Testing

My personal sandbox for learning by doing. Here I replicate tutorials, test ideas, and experiment with different programming languages and technologies.

> ⚠️ **Note:** This is a study repository. The code here is exploratory and not production-ready. My cybersecurity work lives in separate repositories (see below).

## Purpose

- Practice programming fundamentals across multiple languages
- Replicate examples and exercises to understand how things work
- Test small ideas before using them in real projects
- Keep a record of my learning progress over time
